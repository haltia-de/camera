# camera
Камера: a calm camera app for the Haltia tablet — one big button, photos for people and for other programs.

## Как пользоваться

- Видоискатель во весь экран и большая кнопка «Снять». Кнопка «Через 3
  секунды» — чтобы успеть сфотографировать себя.
- После снимка фото показывается крупно, с кнопками «Ещё раз» и «Готово».
  Каждый снимок сохраняется в папке «Изображения/Камера».
- После «Готово» есть кнопка «Отправить»: она показывает большие кнопки
  программ, которые принимают фото, и отдаёт фото выбранной.
- Если камеру занял звонок, Камера пишет «Камера занята звонком» и ждёт.
  Пока окно Камеры в фоне, камера свободна для звонка.
- Если снимок не получился, Камера пишет «Не получилось, попробуйте ещё
  раз», и кнопка «Снять» снова доступна.
- Настроек, видео и переключения камер нет.

## Для других программ

Программа просит снимок через `haltia_kit.camera.take_photo()`. Камера
открывается отдельным окном (`haltia-camera --take-photo`), а «Готово»
возвращает программе путь к фото и закрывает Камеру.

«Отправить» — общее окно haltia-kit (`haltia_kit.share.send()`). Чтобы
программа появилась в нём, в её `.desktop` должны быть `image/jpeg` в
`MimeType` и `X-Haltia-Share=true`; программа запускается с фото как с
открываемым файлом.

## Установка

Пакет `haltia-camera` для Alpine/postmarketOS, или из исходников:
`sh install.sh` (нужны Python 3, PyGObject с GTK 3, GStreamer с
gst-plugins-base и gst-plugins-good и haltia-kit с `haltia_kit.camera` и `haltia_kit.share`).
Без камеры можно попробовать так: `HALTIA_CAMERA_SOURCE=videotestsrc
haltia-camera`.
